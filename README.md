# Project: Insight

An interactive management-style assessment built using HTML, CSS and JavaScript.

https://nkerr2003.github.io/management-style-explorer/

# Overview

Project: Insight is designed to help users reflect on their leadership preferences and explore different approaches to managing teams.

The website combines scenario-based questions and management behaviour statements to produce a management profile with personalised development guidance.

# Features

- 30-question assessment across two sections
- Section A - 12 scenario-based multiple-choice questions
- Section B - 18 five-point agreement statements
- The multiple-choice responses and the statements are randomised to reduce the possibility of patterns appearing
- Combined scoring across six management styles
- Results page that displays strengths, potential challenges and personalised development tips
- Identification of closely matched management tendencies
- Downloadable results
- Management styles library
- About page
- Responsive navigation

# Management Styles 

The assessment explores six approaches:
- Autocratic
- Democratic
- Laissez-faire
- Transformational
- Transactional
- Coaching

# Technologies

- HTML5 for website structure and content
- CSS3 for styling, layouts and responsive design
- JavaScript for questionnaire functionality, scoring and dynamic results

# Assessment Method

The assessment uses two question types:

Section A: Users select their preferred response to 12 real-world scenarios

Section B: Users rate their agreement with 18 management behaviour statements

Each section contributes 50% to the combined management profile score.

The scoring method is a prototype intended more for proof of concept. It has not been scientifically validated and should not be used as a formal measure of leadership ability.
